## 使用方法

### 1. 直接使用订阅链接（推荐）

把下面的订阅地址导入到 Clash / Mihomo / V2RayN / Shadowrocket / Surge 等客户端即可。

| 类型 | 订阅地址（示例） | 说明 |
|------|------------------|------|
| Clash / Mihomo | 见 `subscriptions/clash.txt` | 通用 Clash 订阅 |
| V2Ray / VMess / VLESS | 见 `subscriptions/v2ray.txt` | Base64 或明文 |
| 混合节点 | 见 `subscriptions/mixed.txt` | 多种协议合集 |

> 实际可用链接请查看仓库内 `subscriptions/` 目录最新文件。

### 2. 手动添加节点

仓库中的 `nodes/` 目录会不定期更新公开免费节点示例（JSON / YAML 格式），可自行复制到客户端。
